# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share an activity through WhatsApp, Facebook, or email. Shared links open the
  selected activity, with an option to show all activities.

## Activity difficulty

Activities may include a `difficulty` field set to `Beginner`, `Intermediate`, or
`Advanced`. Leave it out for activities suitable for all levels. The difficulty
filter's **All** option shows only activities without a difficulty; **Any
Difficulty** shows activities regardless of difficulty.
